# Wildvista V2.3 media sources

The photographic hero/destination demo URLs currently use free Unsplash photos selected for Tanzania/safari/Zanzibar context. They are **demo web assets**, not Wildvista-owned photography.

Before commercial launch, replace them with photos Wildvista owns or has permission/licensing to use. Operators can upload their own JPG/PNG/WEBP listing cover image through the Operator Portal, and Admin can upload destination/park images through Admin → Content.
